# 12. Glossary

| Term | Definition |
|------|-----------|
| **Fixer's Notebook** | Dark noir theme with red & gold accents (#1a1815 background) |
| **Stuffer Shack** | Light paper theme with dark ink (#f5f0e8 background) |
| **Decker's Den** | Dark terminal theme with synth purple & orange (#0f0d14 background) |
| **Qualifier** | Short text annotation next to an item description (e.g., "2x", "bio") |
| **Hydration** | Loading persisted state from AsyncStorage into the Zustand store at app start |
| **Fire-and-forget** | AsyncStorage save is called without awaiting — UI update completes first |
| **EAS** | Expo Application Services — build and submit service for Expo apps |
| **Expo Go** | The Expo development app available on app stores for testing managed-workflow apps |
| **Zustand** | A small, fast state management library for React |
| **AsyncStorage** | React Native's asynchronous, persistent key-value storage system |
